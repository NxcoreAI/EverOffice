# 屏幕记忆（PRD 6.9）技术选型定案与 PRD 偏差说明

日期：2026-10-12
状态：待产品确认
范围：仅第 6.9 节「本地屏幕记忆」，其余章节不受影响

## 一、结论摘要

本地 OCR 选型定为 macOS 系统自带的 Vision 文字识别。摘要生成复用现有云端 LLM 通道。本功能不引入任何需要下载的本地模型。涉及 PRD 三处条款文字，行为不变或增强，需要同步修订表述。

## 二、选型依据（实弹验证数据，2026-10-12，Apple Silicon 真机）

1. Vision 是 macOS 系统内置能力，识别模型随操作系统分发，用户零下载。
2. 实测（2560×1440 JPEG、生产同规格）：
   - 典型截图（13 行文字）：全程 0.70 秒，峰值内存 113 MB。
   - 高密度截图（43 行文字）：全程 1.43 秒，峰值内存 134 MB。
   - 中英混排、网址、订单号识别准确率约 99%。
3. 打包形态为随应用内置的小型助手程序（103 KB），仅依赖系统框架，无新增签名证书、无用户授权弹窗。
4. 对比备选方案 PP-OCR ONNX：需下载约 80 MB 模型、纯 CPU 推理、内存峰值 150–300 MB、需自建模型下载管理。Vision 全维度占优。

## 三、PRD 偏差逐条说明

### 偏差 1：「首次安装本地模型展示下载量、设备适配和当前准备状态」

- PRD 原文（关键要求第 1 条）：假设存在需下载的本地模型。
- 现状：OCR 由系统 Vision 承担，零下载。本功能无任何可下载模型。
- 建议改法：
  1. 删除「下载量」展示。
  2. 保留「设备适配」：改为设备门槛检查（芯片架构、可用内存）。
  3. 「准备状态」改为两项真实状态：屏幕录制权限引导状态、采集覆盖范围配置状态。
- 用户影响：首次开启流程更短，少一步大体积下载。

### 偏差 2：摘要的生成位置（PRD 隐含本地，实际为云端）

- PRD 原文（验收）：「模型未就绪时原图与文字可用，摘要显示等待」。原文允许摘要等待，验收行为不变。
- 现状：摘要复用现有云端 LLM 通道生成。卡片其余字段（观察时间、应用、标题、原文片段）全部本机生成，断网完全可用。
- 保护规则（新增，PRD 无此粒度，建议写入 6.9 作为补充）：
  1. 每日摘要调用设上限，超出部分次日补齐。
  2. 仅在设备空闲时段批量生成。
  3. 断网、额度耗尽或未配置 LLM 时，卡片降级显示原文片段，摘要标记等待，恢复后自动补齐。
- 用户影响：
  1. 有网有额度：体验与 PRD 预期一致。
  2. 断网：采集、查找、原图定位、引用全部可用（符合验收），仅摘要延后。
  3. 摘要消耗现有 AI 额度，受每日上限约束，可在设置中关闭。

### 偏差 3：「使用第 3.7 节的分批和预算规则」的计量单位

- PRD 原文：预算规则原定约束本地算力。
- 现状：算力侧仅剩 Vision 识别（实测约 0.7 秒/张，负载可忽略），预算规则的实际约束对象变为云端调用次数与 token 量。
- 建议改法：3.7 规则保留，计量口径改为「每日摘要调用数与 token 上限」，历史补处理的预计处理量展示单位同步改为调用次数。

## 四、验收口径对照（更新后）

| PRD 验收原文 | 实现口径 | 是否满足 |
|---|---|---|
| 断网完成采集、文字查找、轻量整理、原图定位及引用 | 全部本机完成：采集、Vision 识别、规则化整理、原图索引 | 满足 |
| 模型未就绪时原图与文字可用，摘要显示等待 | 触发条件改为：离线、额度耗尽、未配置 LLM。行为一致 | 满足（条件语义更新） |
| 静止画面减少重复推理，微小关键文字变化仍可找回 | 复用现有截图去重与代表帧机制，仅对变化关键帧识别 | 满足 |
| 历史补处理保持原观察日期 | 本地记录原始时间戳，补处理不改写 | 满足 |

前提「模型已下载、设备受支持的本地模式」建议改为「设备受支持的本地模式」。
