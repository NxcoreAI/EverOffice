# 表格页预设（二级）

表格页的第一原则：**表格是页面的主角**——表格由预设撑满内容区，结论写进页标题（行动标题），不配说明小字。

## 通用字段（T1/T2/T3/T5/T6）

```json
{"id":"T1","title":"行动标题","table":{"rows":[["列头1","列头2"],["…","…"]],"colWidths":[1,1.5],"fontSize":14,"emphasisColumn":1}}
```

- `rows`：2~12 行 × 2~8 列；首行是表头（自动加粗）；单元格是字符串或 `{text, bold, color, fill, align, span}`。每行跨列总数必须一致。
- `colWidths`：可选相对列宽（长文本列给 1.5~2，短标签列给 0.6~0.8）。
- `fontSize`：可选 12~14，行多可降到 12。
- `emphasisColumn`：可选，「我方」列序号（0 起）——表头主色底白字、整列加粗提色，只此一列。
- 自动工艺（不用管）：勾选/星级列（✓ ✗ ★）自动居中；纯数字列自动右对齐；含「合计/总计/小计」的行自动加粗提色。

## 各档差异（只差 table 样式，字段同上）

| id | 形态 | 适用 |
|---|---|---|
| T1 | 行线式（表头无底色、只画行线） | 参数对照、指标表、通用数据表（默认推荐） |
| T2 | 深表头（表头深色底白字居中） | 竞品对比、多列对照；行数 ≤6 最稳 |
| T3 | 斑马（无边框、隔行浅底、首列加粗） | 清单/排期/价格表，行 ≥7 |
| T5 | 行线式 + 评单元格 | 评测矩阵——单元格放 ✓/✗/★ 自动居中 |
| T6 | 行线式 + 财务工艺 | 财务/预算/报价——数字右对齐与合计行自动处理；列数 ≤5 最佳 |

表格内容超预算时工具会报错（给估算数字）——砍行、精简单元格文字或拆两页，不缩字号硬塞。

## T4 卡片行式（长文本清单，不用表格元素）

```json
{"id":"T4","title":"…","cards":[{"icon":"check","title":"成员/功能名","body":"两行左右说明"}, …]}
```

2~5 张全宽行卡等高排布；`icon` 可选（Heroicons 名）。适用：成员介绍、功能列表、条款要点。

## T7 双栏对照式（VS）

```json
{"id":"T7","title":"结论写这里","left":{"name":"方案 A","points":["要点1","要点2","要点3"]},"right":{"name":"方案 B","points":[…]},"winner":"right","ratio":"62/38"}
```

- `points` 3~5 条、每条一行（≤26 字）。
- `winner`："left"/"right"/"none"——胜出方卡片主色提亮加边框。
- `ratio` 可选 "50/50"（缺省）或 "62/38"（主张方 62）。

## 选型速查

行少信息密 → T1/T2；行多 → T3；文字长 → T4；打分 → T5；数字重 → T6；二选一 → T7。
