# 有机版式预设（二级）

有机版式原则：**一页一个引力中心**——环绕/循环页引力来自几何中心，错落/斜切页来自唯一焦点卡或斜切色场。骨架坐标由展开器固定，你只填内容；非网格不等于随意。

适用判断：内容天然是「一核心多分支」「闭环循环」「强弱并列」「一刀两半对比」才用本文件；普通并列论点仍走 F2 卡片阵。全篇有机版式 ≤3 页。

## R1 中心辐射页（环绕式）

```json
{"id":"R1","title":"可选页标题","center":"核心词","satellites":[{"name":"分支名","desc":"一行说明"},×6 或 ×4]}
```

- `center` ≤6 字，主色圆心即全页焦点。
- `satellites` 6 个（缺省）或 4 个（更疏朗）——**不排 5 个**（奇数环绕失衡）。
- 每个卫星：`name` ≤7 字、`desc` ≤9 字（说明放不下就不给 desc，只留名字）。
- 至多一个卫星传 `"highlight": true`（主色底反白，标记最重要分支）。

## R2 环形循环页

```json
{"id":"R2","title":"可选页标题","nodes":[{"name":"环节名","desc":"一行说明"},×5 或 ×4],"ghostWord":"飞轮"}
```

或用 KPI 当环心：`"kpiValue":"3.2倍","kpiLabel":"年增速"`（二选一，都不给则环心留空）。

- `nodes` 5 个（缺省）或 4 个，沿环顺时针箭头相连。
- `ghostWord` ≤6 字——环心超大弱化词。

## R3 错落杂志卡片页

```json
{"id":"R3","title":"可选页标题","skeleton":"A","focusPct":48,"focus":{"title":"主卖点","body":"说明"},"cards":[{"title":"卡标题","body":"短说明"},{"image":{"url":"…"}}]}
```

- `skeleton`："A"（缺省，4 卡：左满高大卡 + 右上横卡 + 右下双卡）或 "B"（3 卡）。
- `focus` 三选一：`{"image":{"url":…}}` 主视觉大图｜`{"value":"76%","label":"标注"}` 超大数字｜`{"title":…,"body":…}` 主卖点。
- `focusPct`：焦点卡宽 48（缺省）~62。
- 右列卡：`{title, body}` 文字卡或 `{image:{url}}` 图卡混排。

## R4 斜切分区页

```json
{"id":"R4","claim":"宣言式主张（最多两行）","variant":"topLeft","mode":"compare","left":{"name":"现状","points":["…","…"]},"right":{"name":"本方案","points":[…]},"winner":"right"}
```

- `variant`："topLeft"（缺省，左上楔形色场）或 "bottomRight"（右下镜像）。
- `mode`："compare"（下半两栏对比卡，字段同上，`ratio` 可选 50/50 缺省或 62/38 主张方 62）或 "points"（下半 2~3 张要点卡：`"points":[{"title":…,"body":…}]`）。
- 色场即锚点，全页只这一个斜切。
