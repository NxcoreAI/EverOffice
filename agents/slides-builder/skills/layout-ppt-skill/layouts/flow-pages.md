# 流程与结构页预设（二级）

流程页原则：**方向感唯一**——整页只往一个方向流动（横或竖），节点等距；阶段不超过 6 个，超过就拆页。阶段名 ≤6 字；要点每条 ≤20 字。

## F1 圆点箭头流程页

```json
{"id":"F1","title":"行动标题","banner":"可选阶段主张","steps":[{"name":"节点名","desc":"一行说明"},×3~4]}
```

两组「圆→箭头→圆」横排，节点名 ≤6 字；`banner` 可选（含 `bannerValue` 可选右端大数字）。

## F2 横幅+卡片阵页

```json
{"id":"F2","title":"行动标题","banner":{"text":"主张句","value":"可选大数字"},"cards":[{"title":"卡标题","body":"两行正文"},×3|4|6]}
```

`cards` 数量只能是 3、4（单排）或 6（两排）——5 张无法等分，请增删一条。卡片自动编号 1. 2. 3.。

## F3 时间轴页

```json
{"id":"F3","title":"行动标题","direction":"horizontal","milestones":[{"time":"2024 Q1","event":"事件","done":true},×4~6]}
```

`direction`："horizontal"（缺省，上下交替）或 "vertical"（事件全右侧纵排）。`done` 缺省 false——已完成节点实心主色、未来节点空心。

## F4 阶段路线条页

```json
{"id":"F4","title":"行动标题","stages":[{"name":"阶段名","deliverables":["交付要点1","交付要点2"],"status":"current"},×3~4]}
```

`status`："done"（浅主色底+对勾）/ "current"（主色底白字，唯一强调）/ "future"（素净）。时间自上而下，当前阶段全篇只一个。

## F5 分层架构页

```json
{"id":"F5","title":"行动标题","layers":[{"name":"层名","modules":["模块A","模块B"]},×3~5]}
```

每层左端色带层名（≤6 字），右侧模块小卡等分（每层 ≤6 个模块）；层色自动取图表系列色梯度。

## F6 竖向里程碑页

```json
{"id":"F6","title":"行动标题","milestones":[{"time":"2024-01","event":"事件一两行"},×4~6],"side":{"image":{"url":"…"}}}
```

`side` 可选：`{"image":{"url":…}}` 右侧配图，或 `{"title":"结论标题","body":"结论正文"}` 右侧结论卡；不给则全宽列表。

## 通用

- 节点/圆点尺寸、连线粗细由展开器统一；强调只给一个元素（当前阶段/高亮节点）。
- 流程方向与页序叙事一致（左→右、上→下）；时间永远向右或向下。
