# 布局技能（一级总纲）

分工：风格技能定色板与字级，本技能定结构与几何。用法：create 第 2 步先排节奏表再逐页选预设——读本文件，按「内容形状→版式系」与构图家族节奏模板定页序，给每页指定预设；**填每一类页之前**按「布局选择器」读对应的二级布局文件（填表格页前必读 table-pages.md，依此类推），预设里的坐标骨架直接套用。

布局策略来源：咨询报告式（行动标题+行线表格+一页一论点）、杂志编辑式（不对称分栏+大留白）、主题演讲式（一页一句话）、瑞士网格（严格等分与对齐）。所有预设只定结构与坐标，颜色一律取所选风格的设计系统。

## 网格系统（一切布局的底）

- 画布 1280×720。边距跟 styleParams.spacing：左右边距 **M = spacing.margin**（无 styleParams 时 60，按 4 取整）；栏缝 **G = spacing.gutter**（无则 20）；上边距 40、下边距 40 固定。
- 页标题区 y=40、h=60：标题 32~40pt 左对齐；标题即结论（行动标题），不写「XX 概览」这类中性标题。
- 内容区 y=140 起、y=680 止 → 可用宽 = 1280−2M（M=60 时 **1160×540**）。
- 全篇所有间距只从 4 的倍数里取（8/12/16/20/24/32/40/48）；同方向的间距必须相等。

## 等分公式与速查表

n 等分宽 = (1280−2M − (n−1)×G) ÷ n；纵向把 1280−2M 换成 540。第 k 列左缘 x = M + (k−1)×(宽+G)；除不尽的余数给最后一格。

- M=60/G=20 速查：横向 2 列 570 ｜ 3 列 373 ｜ 4 列 275 ｜ 5 列 216 ｜ 6 列 176；纵向 2 行 260 ｜ 3 行 167 ｜ 4 行 120（373+373+374=1160）
- M 不同时全部按公式重算，禁止沿用 1160 速查值硬套。

## 均匀性法则（反「布局不均匀」的硬规则；R 系有机预设按其骨架自带规则执行，不适用第 2 条）

1. **内容必须碰到内容区底边 680**——主元素（表格/图表/卡阵）按内容区高度撑满，绝不挤在上半部留大片空白；这是最常见的失衡来源。
2. **网格类版式（T/D/F 与卡片阵）同排卡片等宽等高**；多排时列缝上下对齐（左缘永远落在同一组竖线上）。错落只允许出现在 R 系骨架上——不自创错落。
3. **一页一个视觉焦点**：主元素占内容区 ≥50% 面积或最强字重，其余元素从属。
4. **同类信息同字号同对齐**；数字列右对齐成列（千分位/单位统一）。
5. 卡片内文字与卡片边 ≥16px；卡片标题与正文间距 8~12px。
6. 填完每页过一遍自检：间距一致？底边碰到 680？同排等高？焦点唯一？表格列宽按内容分？数字右对齐？

## 构图家族 × 版式权重

styleParams.composition 定全篇构图家族（swiss/editorial/poster/immersive；没有时按 swiss 倾向）。它只调「同内容形状下的变体选择、疏密节奏、大图用量」——上一节的内容形状映射永远优先。括号内为篇内上限，各行上限不得突破「页序节奏」的全局硬上限。

| 家族 | 气质 | 推荐版式（主用） | 允许（点缀） | 限用 |
|---|---|---|---|---|
| swiss 瑞士网格 | 严格等分、对齐、留白克制 | T1 T3 T6 D3 F2 F5 P1c P4 | T2 T4 T5 D1 D2 F1 F3 F4 F6 P7 P8 | R 系合计 ≤1；P2/P9 合计 ≤1；P5 ≤1 |
| editorial 杂志编辑 | 不对称分栏、大留白 | P7 P8 R3 F3 F6 T4 P5 P1c | P4 D5 F1 T1 | T2 T5 各 ≤1；D1 ≤1；R1/R2/R4 各 ≤1；F2 ≤2 |
| poster 海报大字 | 一页一句、超大字/大数字、色场 | P1a P1b P5 D1 D2 R4 P3 | P9 F2 T7 | T3 T6 各 ≤1；D3 ≤2；F5 ≤1；R1/R2/R3 各 ≤1 |
| immersive 沉浸大图 | 大图压字、深底氛围 | P2 P3 P6 P9 R1 | P7 D4 F5 P1b | T 系合计 ≤2；D1/D2 合计 ≤2；R2/R3 各 ≤1 |

### 分栏比例档位（两栏/三区页通用）

栏宽按占比分配（总宽 = 内容区宽 − 缝隙），坐标按 M/G 换算；只用下表档位，不自创比例。

| 场景 | 档位 |
|---|---|
| 图文对照（P7/P6） | 50/50（缺省）、62/38、38/62——图重取 62 图，文重取 38 图 |
| 图表+侧栏（D5/D4） | 70/30（缺省）、62/38——洞察长取 38 |
| 双卡对比（T7/R4 下半） | 50/50（缺省）、62/38——主张方 62 |
| 焦点卡陈列（R3） | 焦点卡 48%（缺省）~62% |

## 页序节奏（BP/汇报类叙事）

排节奏表的顺序：① 按内容形状映射给每页定版式系与候选预设 → ② 套构图家族的节奏模板调变体与疏密 → ③ 过一遍硬约束自查。

封面(P1a 深色大字 / P1b 大色块 / P1c 超大字，三选一、默认 P1a；锚点硬规则见 text-media-pages.md) → 目录(P4) → 团队(P8) → 愿景(P2) → 市场/痛点(D1/P6) → 产品与定位(D4/P7) → 竞品与技术(T2/T5) → 战略与时间(F3/F4) → 融资与财务(D3/T6) → 封底(P9)，全篇 18~24 页。相邻页不同预设；深色章节页(P3)与全宽图表页(D3)各 ≤2；大图页(P2/P9)合计 ≤3（受每页图片上限约束）。有机版式(R1~R4)全篇 ≤3 页，只给天然匹配的内容（生态/闭环/强弱并列/两半对比），穿插在网格页之间换气。

### 家族节奏模板（疏密交替的总纲；plan 的 density 仍是权威，模板只定倾向）

- **swiss**：封面(P1c/P1a)→目录(P4)→[章节(P3)→3~5 页网格内容页，T/D/F 交替且相邻不同 id]×n→封底(P9)。standard/dense 为主，sparse ≤2（由 P4/P5 承担）；大图 ≤1，配图倾向 contain 保信息完整。
- **editorial**：封面(P1c)→目录(P4)→[章节(P3)→2~3 页 P7/P8/T4 与 1 页 R3/F3 错落交替→1 页大留白 sparse(P5)]×n→封底(P9)。每 3~4 页必有一页低密度页换气；图占栏 38~50%，图在左右交替。
- **poster**：封面(P1a/P1b)→[章节页当海报(P3)→1 页 sparse 大字页(P5/D1)→1~2 页 dense 收紧(T6/D3/F2)]×n→封底(P9 大字或大色块)。sparse 与 dense 强交替；大图少（用色场不用图），KPI 大数字即视觉锚点。
- **immersive**：封面(P2 大图压字)→[章节(P3 深底)→1 页 P6/P9 沉浸页→1~2 页数据/内容页(D 系/P7/R1)]×n→封底(P2/P9)。大图页顶格用到全局上限 3；深底页 ≤2；standard 为主，sparse 由大图页承担。
